# 🚀 Curso JavaScript

Este repositório contém o conteúdo do seu **curso de JavaScript** destinado ao estudo da linguagem, com exemplos, exercícios e projetos práticos para quem está aprendendo programação. O foco principal é a prática e entendimento de conceitos fundamentais da linguagem JavaScript, usada principalmente para tornar páginas web interativas e dinâmicas. 

---

## 🎯 Objetivo do Projeto

O principal objetivo deste repositório é:

- Servir como **exercício prático de JavaScript**
- Organizar exemplos aprendidos no curso
- Reunir exercícios e pequenos projetos
- Ajudar no aprendizado da linguagem JavaScript, seja para front-end ou lógica de programação geral

JavaScript é uma linguagem essencial para desenvolvimento web, permitindo manipular conteúdo no navegador, criar efeitos interativos e desenvolver aplicações completas.
